# 📄 MergePDF

> ⚠️ **MVP em desenvolvimento** — o app é funcional, mas ainda há muitos pontos de melhoria planejados para as próximas versões.

**MergePDF** é uma aplicação desktop com interface gráfica para **mesclar múltiplos arquivos PDF em um único documento**, de forma simples e intuitiva. Disponível para **Linux** e **Windows**.

## ✨ Funcionalidades

- 📂 **Seleção múltipla de arquivos** — adicione vários PDFs de uma vez pelo explorador de arquivos
- 🔀 **Reordenação dos arquivos** — organize a ordem dos PDFs antes de mesclar
- 🗑️ **Remoção individual** — remova arquivos específicos da lista sem precisar recomeçar
- 💾 **Escolha do destino** — defina o nome e o local onde o PDF mesclado será salvo
- ✅ **Feedback visual** — mensagens de sucesso e erro exibidas diretamente na interface

---

## 🖥️ Como usar
1. Abra o MergePDF
2. Clique em Adicionar para selecionar os arquivos PDF
3. Reordene ou remova arquivos conforme necessário
4. Informe o nome do arquivo de saída
5. Clique em Criar e escolha onde salvar
6. Pronto! O PDF mesclado será gerado no local escolhido
