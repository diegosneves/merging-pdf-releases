# 📦 MergePDF — Releases Oficiais

Repositório público de distribuição dos instaladores do **MergePDF**,
uma aplicação desktop para mesclar arquivos PDF de forma simples e intuitiva.

> ⚠️ Este repositório contém **apenas os instaladores**.
> O código-fonte é mantido em repositório privado.

---

## 📥 Download

Acesse a aba [**Releases**](../../releases/latest) para baixar a versão mais recente.

| Plataforma | Arquivo | Como instalar |
|---|---|---|
| 🐧 Linux (Ubuntu/Debian) | `.deb` | `sudo dpkg -i MergePDF-*-linux.deb` |
| 🪟 Windows 10/11 | `.exe` | Execute e siga o assistente |

---

## 🚀 Como usar

1. Baixe o instalador da sua plataforma
2. Instale normalmente
3. Abra o **MergePDF**
4. Adicione os arquivos PDF que deseja mesclar
5. Defina o nome do arquivo de saída
6. Clique em **Criar**

---

## 🛠️ Requisitos

| Plataforma | Requisito mínimo |
|---|---|
| Linux | Ubuntu 20.04+ ou derivados Debian |
| Windows | Windows 10 64-bit |
